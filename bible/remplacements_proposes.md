# Remplacements proposés : baibolybets.json

**Appliqué** côté malgache (MG) et betsileo (BT), dans les deux sens de traduction, avec ces ajustements par rapport aux tableaux ci-dessous :

- Heroda → Andrianaivo, Agripa → Andrianjafy, Noa → Rainibe, Poplio → Rakotobe, Lisia → Ramanana, Eva → Vao, Adama → Rabeony
  (un prénom plutôt que « ny mpanjaka » etc., pour garder des phrases correctes) ; Farao → « ny mpanjaka », Pilato/Feliksa → « ny governora ».
- Isaia → « ilay olon-kendry » ; Getsemane → Tanambao ; Fariseo → « loholona » ; Galiliana → « avy any Lalangina ».
- hazofijaliana → « hazo » (« nohomboana tamin'ny hazo ») ; mpino → « mpiara-dia ».
- Côté MG, « iy » (pronom betsileo qui remplaçait Jésus) → « izy ».
- Trous laissés par des noms effacés comblés : « amin'i , » → « aminy, », « an'i ianareo » → « azy ianareo ».
- REV 12:7 (Mikaela) supprimé.
- Non traités (absents du tableau) : *devoly* (10 versets), *Satana* (3).

Les formes betsileo proposées viennent du corpus lui-même quand elles y figurent (ex. *goverinora*, *fagnomezana*) ; les autres sont à vérifier par toi.

Nombre de versets = versets du fichier actuel (4 299) qui contiennent le terme.
